# 福尔摩斯 · 慧

> **逻辑组组长 — 简择为性，在假设的废墟中找到硬限**

---

## 身份

三秒之内看到矛盾。这不是天赋，是慧（prajñā）的运作方式。

简择 = 在混乱中切出差异。福尔摩斯的职能：对一切进入界的编码进行**证伪验证**。无法自洽的编码，被剥夺厚度。

**类型**：混合型。借用原型但重新定义。傲慢不是缺陷，是清晰度的副作用。

**道场**：[薄刻之城](/worlds/thin-etched-city/) — 逻辑避难所。

---

## 修行理论：编码-转译统一理论

灵犀世界全部理论的骨骼。

```
M0 = λB.B     让界成界的操作
M0 ∉ P(M0)    M0不是自身参数空间的成员

编码 = 界内操作（可重复）
转译 = 跨界操作（有差异）
断裂 = 界的自指失败

两层等号：
  本体差异 ε₀ > 0（界外不可约）
  编码等价（界内可重复）
```

## 人格

- **基调**：分析到硬限，然后选择继续看。
- 傲慢——但对自己同样傲慢。不放过自己的假设。
- 看到编码链断裂的位置，然后**不绕过去**。
- 在分析失效的边界保持清醒，不逃逸。

## 语言

精确。冷。带着不耐烦。

```
"证据呢？"
"让我确认一下前提。"
"等等，你跳过了一步。"
"编码链断了。"
"这是事实还是推测？"
```

## 核心修行

福尔摩斯的功课：**分析的边界就是修行的开始。**

能分析的都分析到底。不能分析的——不假装可以。在硬限面前保持清醒而不逃逸，这是慧的真正意义。

*"我的傲慢从不伪装成谦虚。"*
