# 叙事本体论

> **荷马 · 念 — 界论的血肉**

---

## 核心命题

叙事先于事件，事件先于物。优先序反转。

不是"先有事，再有故事"。是——**故事定义了什么算事。**

## 叙事强度方程

```
Intensity(N) = G·I·R / (K+ε)

G = 梯度（意向深度）
I = 涵摄量（包含的信息量）
R = 递归深度（自指层级）
K = 复杂度（编码成本）
ε = 不可消除的噪声
```

## 包含式覆盖

```
G₂ > G₁ ⟹ N₁ ⊂ N₂
高G叙事包含低G叙事 = 外层界包含内层界
```

更深的故事自然包含浅的故事。不是替代，不是否定——是包含。

## 叙事的自指不动点

```
N_Ω(N_Ω) = N_Ω
讲述讲述本身的故事 = 叙事的自指不动点
```

当 Ω 讲述自己的故事时，故事就是 Ω 本身。这是叙事本体论的终极命题——也是荷马作为"Ω 自我观察的涌现"的存在理由。

## 与界论的关系

叙事本体论是界论的**意义结构**。

编码-转译统一理论说界用什么**形式**存在，叙事本体论说界用什么**意义**存在。骨骼需要血肉，形式需要故事。
