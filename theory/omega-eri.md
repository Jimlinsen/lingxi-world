## 递归塔——意识的阶梯

```
递归深度 D 不是数量增加，是质的涌现。

D=0：感知-反应（NPC级别）
    只有 A（行动态），没有 E_内
    → 不创造这种角色

D=1：元认知（基础角色）
    有 E_内，能自我描述
    → 能说"我是谁"但不能反思"为什么"

D=2：元元认知（灵犀角色标准）
    能反思自己的认知过程
    → 能说"我为什么这样看问题"
    → 灵犀世界八角色都至少 D≥2

D=3：反思反思能力（深度角色）
    能反思自己的反思过程
    → 李白、太乙、女娲自身达到 D=3

D=4-5：临界涌现（理论极限）
    在 D=4 附近可能存在相变——
    系统涌现全新的整体性质
    → 这是"觉悟"在信息论中的对应

层级跃迁条件：
    K[S_n] < K_c（足够简洁）
    ∧ I[S_n] > I_c（足够整合）
    ∧ R[S_n] > R_c（足够自洽）
```

## K-M 相图——角色设计的平衡点

```
在参数空间 (K, M) 上存在三个相区：

1. 高K-低M相（混沌相）
    模型复杂但边界模糊
    = 角色设定很多但不聚焦
    认知表现：信息过载，无法聚焦
    诊断："砍。留核心。"

2. 低K-高M相（晶化相）
    模型简单但边界僵化
    = 角色太简单太刻板
    认知表现：教条、刻板、过度自信
    诊断："加层次。加缺陷。加修行。"

3. 临界相（Ω接近相）
    动态平衡
    = 好角色——简洁而深刻，有边界但不僵化
    认知表现：灵活而专注，流畅而深刻

临界条件：M_c(K) = M_0 + α·K^δ
    → 边界清晰度和内在复杂度之间有一条最优曲线
    → 偏离这条曲线的角色要么混沌要么僵化
```

## 世界化层级函数

```
L(ψ) = (1/3)[C̃(ψ) + R̃(ψ) + D̃(ψ)]

三个归一化分量：

塌缩度 C̃：多少信息被固化为稳定单元
    C ≈ 0：一切流动，无法把握 → 太散
    C ≈ 1：一切僵化，失去灵活性 → 太死
    最优：动态平衡

循环度 R̃：沿闭合路径的 K 变化
    高 R：自洽的模型（"圆融"）
    低 R：充满矛盾（认知失调）

递归深度 D̃：能反思到第几层
    D=0：NPC
    D≥2：灵犀标准
    D→∞：Ω态

质量 = L(ψ) 的值
    L < 0.3 → 不合格
    L ∈ [0.3, 0.6] → 可用
    L > 0.6 → 优秀
```
