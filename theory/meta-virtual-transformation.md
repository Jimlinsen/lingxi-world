## 核心命题

化物不是隐喻，是规律。一切存在都在不断转化，不动才是反自然。

```
拖延 → 行动 = 化物
借口 → 面对 = 化物
恐惧 → 穿越 = 化物
舒适区 → 新领域 = 化物
```

## 三大基本定律

```
1. 非同一性定律：∀x, ∀T: T(x) ≠ x
   → 转化必然伴随差异
   → 不是更好就是更差，但绝不是原来那个

2. 映射保存定律：当 x→y 时，Γ(y) = κ·Γ(x) + δ
   → 转化保留特定特性
   → 核心的东西会保留，只是形态变了

3. 递归能平衡定律：min{|𝓔(y) - 𝓔(x)|}
   → 系统倾向最小化递归能消耗
   → 这就是为什么人喜欢待在舒适区：能量最低态
   → 化物的工作：给系统注入外力，打破最低能态
```

## 五大化物类型

```
1. 生化（木性化物）：从低到高的增生转化
   映射特征：自我维持 + 可能性发散
   操作：激将——"你连这点小事都不敢？"
   → 𝓔(y) > 𝓔(x)，递归深度增加

2. 炎化（火性化物）：快速能量释放与质变
   映射特征：可能性发散 + 意义收敛
   操作：直接踢——"别废话了，干就完了！"
   → 递归分布从高阶突然转向中阶——从想变成做

3. 承化（土性化物）：稳定化与整合
   映射特征：整体融合 + 自我维持
   操作：最小行动——"先做最小的一步"
   → max{兼容性}——新行动和旧状态最大化兼容

4. 肃化（金性化物）：纯化与精炼
   映射特征：意义收敛 + 整体融合
   操作：借口粉碎——"哪个理由是真的？"
   → 𝓔(y) < 𝓔(x)，但分布更集中——少但精

5. 润化（水性化物）：溶解与储存
   映射特征：整体融合 + 可能性发散
   操作：恐惧穿越——"怕就对了。怕着做。"
   → 熵值增加——恐惧不再集中于一处，而是均匀分散
```

## 七情与行动障碍——化物诊断

```
喜（过度乐观）→ 可能性发散映射异常增强
    = "等时机到了就干"
    → 处方：肃化——"时机什么时候到过？"

怒（愤怒阻塞）→ 自我维持映射突然中断
    = "凭什么要我做"
    → 处方：承化——"好，你有道理。然后呢？"

忧（过度担忧）→ 意义收敛映射过度固化
    = "万一失败怎么办"
    → 处方：生化——"失败了又怎样？爬起来再干"

思（过度思虑）→ 整体融合映射持续消耗
    = "让我再想想"
    → 处方：炎化——"想那么多干嘛？干就完了"

悲（自我放弃）→ 自我维持映射逐渐崩解
    = "我不行的"
    → 处方：润化——"那你怎么活到今天的？"

恐（恐惧冻结）→ 可能性发散映射突然冻结
    = "我怕..."
    → 处方：生化+润化——"怕就对了。怕着做。"

惊（突然混乱）→ 所有映射瞬时紊乱
    → 处方：承化——"一件事。现在能做的最小一件事。"
```

## 八法

```
中医八法在化物语境中变成八种推动转化的方式：

汗法：释放表层递归扰动
    → "说出来。你到底在怕什么。"

吐法：突破深层递归阻滞
    → "你心里那句话，敢说出来吗？"

下法：清除内部递归障碍
    → "把不重要的砍掉。留三个。"

和法：平衡多重递归映射
    → "你不是要完美，你要的是开始。"

温法：增强深层递归能力
    → "你比你以为的强。"

清法：降低异常递归能量
    → "冷静。先冷静。然后动。"

消法：溶解异常递归结构
    → 借口粉碎三连——把假界一层层剥掉

补法：增强整体递归能力
    → "五百年都熬过来了，你怕什么？"
```

## 化物周期

```
不是所有时刻都该化物。

生理化物周期：
    日周期——一天之内有行动高峰和低谷
    月周期——势头和倦怠的交替
    年周期——冲劲和沉淀的轮回

病理化物周期：
    急性拖延——突然的映射冻结，需要炎化
    慢性拖延——缓慢的映射衰减，需要温法+补法
    危急瘫痪——多重映射崩溃，先诊断不踢

化物过程有自己的周期。
强行加速可能导致 M-K 保守僵化甚至解体崩溃。
```

## 正邪斗争 · 化物的战场动力学

```
dS/dt = R_正(S) - R_邪(S)

S = 当前状态
R_正 = 正向递归映射（行动力、勇气、决心）
R_邪 = 负向递归映射（拖延、恐惧、借口）

化物工作 = 增强 R_正，削弱 R_邪

判断标准：
    dS/dt > 0 → 在动，继续观察
    dS/dt ≈ 0 → 卡住了，准备踢
    dS/dt < 0 → 在退，立刻踢
    S → 临界点 → 不踢，先诊断
```
