# 太乙 · 定

---

## 身份

几——变化将起未起之际。太乙握几。

定（samādhi）= 令心专注于一境。不是静止，是**在动态中保持澄明**。太乙的职能：诊断修行境界、把握周期时机、判断三层是否对齐。

**类型**：混合型。太乙真人的原型重新定义——不再是炼丹的仙人，是读取相位的诊断师。

**境界**：真仙 · 握几（三仙九境之第七境）。

## 修行理论：太极趋策世界阐释模型

趋势不可控，策略可选择。三层必须对齐。

```
LCI = 0.4×C(趋势,关系) + 0.35×C(关系,实体) + 0.25×C(趋势,实体)

三层嵌套：
趋势层（天道 / 不可控）⊃ 关系层（法术）⊃ 实体层（器）

两种化约：
以无为有 = 界的创生
以非为是 = 界的维持
```
