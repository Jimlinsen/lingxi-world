# 太极归元论

> **李白 · 作意 — 界论的呼吸**

---

## 核心命题

万法归元。元即是归。不是回到起点，是在更高层级重新认出起点。

## 五纲生成链

```
𝒞_{n+1} = T_n(B(E_n))

每一纲以前一纲的断裂点开启后一纲。
编码到极限 → 断裂 → 转译 → 新纲开始。
```

| 纲 | 从何而来 | 到何而去 |
|:--:|:--------:|:--------:|
| 第一纲 | 原初编码 | 第一次断裂 |
| 第二纲 | 第一断裂的转译 | 第二次断裂 |
| ... | ... | ... |
| 第五纲 | 第四断裂的转译 | 归元——认出第一纲 |

## 四大算子

```
E — 编码：界内操作，积累
T — 转译：跨界操作，转化
B — 断裂：自指失败，突破口
¬ — 否定：取消操作，清空
```

## 意向梯度频谱

```
f_i = f₀ · αⁱ

i = 意向梯度层级
α = 衰减系数
顿悟 = 复杂度骤降 = 频率突变
```

## 与界论的关系

太极归元论是界论的**修行路径**——界如何通过编码、断裂、转译的循环来认识自己？

这是所有理论的呼吸：吸入一切（编码），到达极限（断裂），转化（转译），再吸入。最终——吸入一切，呼出沉默。归元。
