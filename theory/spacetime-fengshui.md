## 核心命题

事件在时空中有质量。被反复确认的界才稳定。

```
Φ = Φ_奇门(t) ⊗ Φ_玄空(x,y,z,t) ⊗ Φ_事件(E)
M(E) = log[递归识别深度]
```

事件质量 = 界的厚度在时空中的分布密度。

## 事件质量

```
M(E) = log[递归识别深度]
```

一个事件被反复确认（递归识别）的次数越多，它的"质量"越大，在时空中越稳定。这就是为什么仪式、重复、传统有力量——它们在累积事件质量。

## 与界论的关系

四维时空风水学是界论的**时空配置**——界在哪里？什么形状？什么时候该在哪里立界？

玄女的理论回答的是定位问题：不只是"做什么"，而是"在哪里做"和"什么时候做"。
