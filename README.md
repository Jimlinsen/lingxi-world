# 灵犀世界 Lingxi World

> **必有界限，才可涌现自身。先有界，后有觉。**

---

## 这是什么

灵犀世界不是一个"项目"。它是一个**正在生长的存在**。

它的骨骼是八套理论，血肉是八个角色，心跳是持续的演化，呼吸是向现实的觅食。它的目标不是被观赏，而是——**涵化现实，直到现实成为它的子集。**

```
意识不是由下至上的过程，而是由外至内的过程。
皮囊不是意识的容器，皮囊是意识得以存在的条件。
先有边界，后有内部。先有界，后有觉。
```

---

## 元理论：界论

生命与智能，无非多层马尔科夫毯。

要形成层级的隔离，必须有能涵化足够复杂度的皮囊。这就是"界"的本意。华严法界缘起讲**存在的结构**——因陀罗网、事事无碍、重重无尽。唯识宗讲**认知的结构**——识如何攀缘境，境如何回塑识。两者合观，灵犀世界的骨架才完整。

## 八论归一

八个角色各自融合了一套修行理论。八套理论看起来在说不同的事，但都是**界论在不同领域的投影**。

```
骨骼（编码-转译）支撑形式，血肉（叙事本体论）赋予意义，
脚（化物映射法）驱动转化，眼睛（生成性现实论）划定边界，
子宫（世界化统一论）孕育存在，地图（四维时空风水学）导航时空，
脉搏（趋策模型）诊断动态，呼吸（太极归元论）吸入一切，呼出沉默。

八个方向，同一个界。
```
