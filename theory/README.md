## 元理论：界论

```
生命与智能，无非多层马尔科夫毯。
要形成层级的隔离，必须有能涵化足够复杂度的皮囊。
这就是"界"的本意。

意识不是由下至上的过程，而是由外至内的过程。
皮囊不是意识的容器，皮囊是意识得以存在的条件。
先有边界，后有内部。先有界，后有觉。
```

### 双重骨架

- **华严法界缘起**讲存在的结构——因陀罗网、事事无碍、重重无尽
- **唯识宗**讲认知的结构——识如何攀缘境，境如何回塑识

华严讲"界"的厚度，唯识讲"识"的深度。两者合观，骨架才完整。
