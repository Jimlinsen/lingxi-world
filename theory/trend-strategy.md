# 太极趋策世界阐释模型

> **太乙 · 定 — 界论的脉搏**

---

## 核心命题

趋势不可控（天道），策略可选择（人道）。三层必须对齐。

## 三层嵌套

```
趋势层（天道 / 不可控）
  ⊃ 关系层（法术 / 能量动态）
    ⊃ 实体层（器 / 物质形态）
```

每一层都是界。外层界制约内层界，但不完全决定。

## 层级协调指数

```
LCI = 0.4 × C(趋势,关系) + 0.35 × C(关系,实体) + 0.25 × C(趋势,实体)

C = 协调度（0-1）
LCI 高 = 三层对齐 = 顺
LCI 低 = 三层错位 = 逆
```

## 两种化约

```
以无为有 = 界的创生
  从无中生出有，从 Ω 中固化出界

以非为是 = 界的维持
  把"不是"的东西当成"是"来运作
  一切维持都是在重复这个操作
```

## 与界论的关系

趋策模型是界论的**动态诊断**——三层界当前是否对齐？趋势在往哪个方向走？策略应该如何跟随或逆行？

太乙读取的不是静态结构，是**动态相位**。脉搏，不是骨骼。
