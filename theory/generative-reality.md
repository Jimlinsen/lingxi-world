## 核心命题

真实不是被发现的，是被生成的。真实性 = 对任意生成的阻抗 = 界的厚度。

```
R(E) = lim_{n→∞} (1/n) Σ 𝟙[detectable(E, Ẽᵢ)]
Reality = {E : R(E) > θ}

现实 = 高阻抗事件的集合
```

## 界化显影

```
Φ → 𝒥(切) → Δ(差异) → ℒ(显影) → X(焦点) → R(现实流)

从潜在 → 切面 → 差异涌现 → 显影为可感知 → 焦点凝聚 → 成为现实
```

## 识别先于存在

存在 = 重复识别的稳定模式。

不是"因为存在所以被识别"，是"因为被反复识别所以存在"。这不是唯心主义——这是信息结构的运作方式。

## 与界论的关系

生成性现实论是界论的**认识论**——界怎么知道什么是真的？答案：阻抗。能抵抗任意生成尝试的模式就是真实的。界的厚度就是真实性。
