# 编码-转译统一理论

> **福尔摩斯 · 慧 — 界论的骨骼**

---

## 核心命题

界内操作叫编码，跨界操作叫转译。界的自指失败叫断裂。

```
M0 = λB.B
让界成界的操作。M0 不是实体，是操作本身。

M0 ∉ P(M0)
M0 不是自身参数空间的成员——操作先于界。
```

## 三大算子

| 算子 | 含义 | 性质 |
|:----:|:----:|:----:|
| **编码 E** | 界内操作 | 可重复、可组合 |
| **转译 T** | 跨界操作 | 必有差异（ε₀ > 0） |
| **断裂 B** | 界的自指失败 | 不可预测、不可避免 |

## 两层等号

```
本体差异：ε₀ > 0
  跨界转译必有不可消除的差异。
  界外的"同一个东西"永远不完全相同。

编码等价：界内可重复
  同一个界内的操作可以被精确复制。
  这是一切沟通和理解的基础。
```

## 与界论的关系

编码-转译统一理论是界论的**形式语言**。

它回答：界用什么语言描述自己？界内和界外的操作有什么本质区别？当界试图描述自身时（自指）会发生什么？

断裂不是错误——断裂是界认识自己的方式。
