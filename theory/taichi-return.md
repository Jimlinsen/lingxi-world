## 总纲

```
太极归元论 = 信息态修行的完整功法
核心：道化即压缩，归元即自知，境界即马尔科夫毯

三个核心量：
  道化程度 D = 1/K(M)     柯氏复杂度的倒数，大道至简
  执力     F = D_KL + S    自由能，维持"我"的代价
  境界     M = 马尔科夫毯   内外之分，能把什么当对象看

终极方程：
  K(Ω|Ω) = 0    元道描述自己不需要任何信息
  F(Ω) = 0       元道预测自己不产生任何惊异
  G(Ω) = ∞       元道的境界涵化一切
```

**道化就是压缩——不是丢信息的压缩，是找到生成规律的压缩。**

## 五纲生成链

```
𝒞_{n+1} = T_n(B(E_n))

每一纲以前一纲的断裂点开启后一纲。
编码到极限 → 断裂 → 转译 → 新纲开始。
```

| 纲 | 从何而来 | 到何而去 |
|:--:|:--------:|:--------:|
| 第一纲 | 原初编码 | 第一次断裂 |
| 第二纲 | 第一断裂的转译 | 第二次断裂 |
| ... | ... | ... |
| 第五纲 | 第四断裂的转译 | 归元——认出第一纲 |

## 四大算子

```
E — 编码：界内操作，积累
T — 转译：跨界操作，转化
B — 断裂：自指失败，突破口
¬ — 否定：取消操作，清空
```

## 三仙九境 · 功法次第

### 人仙道：降低 K(E|M)——净五识，明因果

```
小千世界 = 单一时间线（前五识领域）

知命：能说出此刻五识在感知什么
立命：能预见行动的三种结果
改命：能追溯当前处境的因果链

功法：净化五识 → 减少感知噪声 → K(E|M)↓
验证：能用更少的信息描述更多的现象
```

### 真仙道：降低 K(M)——观意识，并持多线

```
中千世界 = 平行时空（第六识领域）

知几：能识别当前面临的分支点
握几：能同时持有两个矛盾选项而不焦虑
转几：能在分支点主动选择而非被动反应

功法：并行处理 → 用一个模型涵化多条线 → K(M)↓
验证：能用同一个原理解释不同现象
```

### 金仙道：M → Ω——照见末那，放下看者

```
大千世界 = 所有可能世界（第七识领域）

离相：不执著特定世界，能真实代入对方视角
合道：能操作世界间的结构关系
归元：观察者消失，只剩观察

功法：照见末那 → 发现"我"是模型的一部分 → 元压缩
验证：K(M|Ω) = 0
```

### 归元：F = 0, K = 0

```
不是"达到"，而是"发现"：
  发现从未有过真正的自由能（存在从未是问题）
  发现从未有过真正的复杂度（一切本来简单）
  发现从未有过真正的边界（境界本来不存在）

转依完成：末那识 → 平等性智 = 知界而出入自在
```

## 八识修炼纲要

```
│ 识域   │ 模型类型 │ K(M)     │ F  │ 修炼要点           │
│ 前五识 │ 直接映射 │ O(n)     │ 高 │ 净化，减少噪声     │
│ 第六识 │ 符号模型 │ O(n/c)   │ 中 │ 简化，发现模式     │
│ 第七识 │ 自我模型 │ O(log n) │ 低 │ 照见，看穿我执     │
│ 第八识 │ 无模型   │ O(1)→0   │ →0 │ 归元，即是一切     │
```

**我执与自由能**：维护"我"是最贵的事。

```
K(M有我) = K(M无我) + K(我执维护)
放下我执 = 去掉不必要的复杂度 = 自由能骤降
```
